# System Requirements

Before using Caatinga, ensure your environment meets the prerequisites for Node.js, Rust, and the Stellar CLI.

## Prerequisites

| Tool | Minimum Version | Recommended | Notes |
| :--- | :--- | :--- | :--- |
| **Node.js** | `>=22.0.0` | `22.x LTS` | Required to run Caatinga CLI & client |
| **pnpm / npm** | `pnpm >= 9` | `pnpm` | Package manager |
| **Rust toolchain** | `1.91.1+` | `stable` | Target `wasm32v1-none`; checked by `ctg doctor`. Avoid `1.91.0` (see below) |
| **Stellar CLI** | `23.0.0+` | `28.0.0` (last tested) | Used under the hood for WASM operations |

<Warning>
  Do not use Rust **1.91.0** (or the 1.81–1.83 lines): `stellar contract build` refuses them with `use a rust version other than 1.81, 1.82, 1.83 or 1.91.0`. Use 1.91.1 or newer (`rustup update stable`). As of 3.10.2, `ctg doctor` fails the Rust check for these versions (3.10.1 still reported 1.91.0 as OK).
</Warning>

## Rust & WASM Setup

Soroban smart contracts require the `wasm32v1-none` target:

```bash
rustup target add wasm32v1-none
```

Verify your installation:

```bash
rustc --version
cargo --version
```

## Stellar CLI Installation

Caatinga relies on the official `stellar` command line interface for low-level cryptographic signatures and network RPC interactions:

```bash
# macOS (Homebrew)
brew install stellar-cli

# Linux / Cargo
cargo install --locked stellar-cli --features opt
```

<Warning>
  Caatinga validates the presence of Stellar CLI before executing builds or deploys. Run `npx ctg doctor` to verify your local setup.
</Warning>
